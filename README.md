# Moodly — MVP (Statik Sürüm)

Bu, Moodly fikrinin *en basit çalışan prototipi*dir. Sunucuya ihtiyaç duymaz; yalnızca tarayıcı ve GitHub Pages ile çalışır.

## Özellikler
- Günlük ruh hali kaydı (1–5 puan, duygu, not)
- Haftalık çizgi grafik (Chart.js ile)
- Basit içgörü (ortalama ve trend)
- Veriler **localStorage**'da tutulur

## Çalıştırma
1. Dosyaları bir klasöre indirin veya GitHub'a yükleyin.
2. `index.html` dosyasını çift tıklayıp tarayıcıda açın.
3. Kayıt ekleyin, grafik ve içgörüleri görün.
